# Segurança e contacto

## Para lojas e operadores de sites

Se és responsável por um site cujos preços são recolhidos por este projeto e queres
reportar um problema — carga excessiva, recolha que não devia estar a acontecer, dados
apresentados de forma incorreta, ou um pedido de exclusão — abre um contacto direto
pelos canais abaixo. Não é preciso passar por advogado para isto ser tratado.

Compromissos do projeto:

- **Exclusão a pedido.** Um pedido de um operador de site para deixar de recolher o seu
  domínio é cumprido, sem exigir justificação.
- **Resposta rápida a carga.** Se a recolha estiver a causar carga, o domínio é
  suspenso primeiro e discutido depois.
- **Correção de dados.** Uma observação de preço é um facto histórico e não é alterada;
  se estiver errada por erro de extração, é marcada como inválida e a correção fica
  visível, com a data em que foi feita.

## Para vulnerabilidades de segurança

Reporta em privado, **não** abras uma issue pública.

- GitHub Security Advisories: usa o separador *Security* > *Report a vulnerability*.
- Em alternativa, contacto por email — ver o perfil do mantenedor no GitHub.

Pedimos que não divulgues publicamente antes de haver correção disponível. Sem programa
de recompensas: este é um projeto pessoal, sem orçamento.

## Âmbito

Este projeto **não recolhe, processa nem armazena dados pessoais**. Se encontrares dados
pessoais no repositório ou na base de dados, isso é por si só um bug de severidade alta
— reporta pelo canal privado.

O conteúdo HTML recolhido é tratado como **dado a analisar, nunca como instrução a
seguir**. Relatórios de tentativas de injeção via conteúdo de páginas são bem-vindos.
